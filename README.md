
# TypeScript 2D Shooting Game (Complete)

TypeScript と HTML5 Canvas で実装された、ブラウザで動作するオーソドックスな2Dスクロール・シューティングゲームです。外部のゲームエンジン（Phaser や Pixi.js など）に依存せず、すべてのゲームループ、衝突判定、描画ロジックをピュアな TypeScript で自作しています。

## 🚀 主な機能と実装アルゴリズム

- **ゲームループとメモリ管理**: `requestAnimationFrame` を用いた 60FPS のループ。画面外に出たオブジェクトを配列から自動削除するクリーンアップ処理（メモリリーク防止）。
- **キーボード入力管理**: OS特有のキーリピートの引っ掛かりを解消し、滑らかな斜め移動を実現するフラグ管理（`InputManager`）。
- **軽量な衝突判定**: 平方根（`Math.sqrt`）の計算を排除し、半径の和の二乗と比較することで負荷を大幅に削減した**円判定アルゴリズム**。
- **誘導弾（ホーミング）**: `Math.atan2` を用いて、最も近い敵への角度を毎フレーム計算・補間して追従するミサイル。
- **アイテムの自動吸着**: 自機とアイテムの距離を計算し、一定範囲内に近づくと自機へ高速に吸い寄せられるマスコット吸着システム。
- **パーティクルシステム**: 敵撃破時に、ランダムな方向と速度を持つ複数の火花を発生させ、時間経過（ライフ）とともにフェードアウト（透明度変化）させる爆発エフェクト。
- **パララックス（多重）スクロール**: 遠くの星は遅く、近くの星は速く動かすことで、宇宙空間の奥行きと疾走感を表現する背景描画。
- **無敵時間と点滅エフェクト**: 被弾後に一定時間の無敵状態を付与。タイマーの余り計算（`%`）を利用したシンプルな周期点滅ロジック。

## 🎮 操作方法

- **移動**: `矢印キー (↑ ↓ ← →)` または `W, A, S, D`
- **ショット**: 自動で連射されます
- **リスタート（ゲームオーバー時）**: `Enter キー`

### パワーアップシステム
敵を倒すと一定確率で出現する**ピンクのアイテム**を回収すると、スコアが加算され、自機の `POWER` レベルが上昇します。
- **Lv.1**: 正面への通常弾のみ
- **Lv.2〜3**: 通常弾に加えて、敵を自動で追尾する**水色の誘導弾（ホーミング弾）**が追加発射されます。

## 🛠 開発環境の構築と動かし方

### 前提条件
- [Node.js](https://nodejs.org/) がインストールされていること

### 1. 依存関係のインストール
プロジェクトのルートフォルダで以下のコマンドを実行し、TypeScript コンパイラをインストールします。

```bash
npm install
2. コンパイルの実行
1回のみコンパイルする場合:
Bash
npx tsc
開発中（ファイルの変更を監視して自動コンパイルする場合）:
Bash
npx tsc -w
コンパイルが成功すると、/dist フォルダ内に game.js が生成されます。

3. ゲームの起動
index.html を任意のブラウザで開くことで、ゲームをプレイできます。
